# D3: Use Case Diagram

Diagram ini memvisualisasikan batasan sistem dan interaksi antara aktor dengan fitur utama dalam Sistem Manajemen Lantai Gedung.

![Gambar Use Case Diagram](diagram/D3_Use_Case_Diagram.png)

**Keterangan Aktor:**
* **Admin Kos:** Memiliki akses penuh untuk mengelola data kamar, meregistrasi penyewa baru, dan menghitung tagihan bulanan.
* **Penyewa (Tenant):** Memiliki akses terbatas untuk sekadar login, mengecek ketersediaan kamar, dan melihat nominal tagihan mereka sendiri.
